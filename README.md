# أرخبيل الحروف — حروف مع عماد (رمضان ٢٠٢٧)

موقع مسابقة قراصنة متعدد اللاعبين: خريطة مرسومة، سفن بأعلام الطواقم، اختيار الحركة اليومية، كشف الحركات، الحوت، الكنوز، الترتيب، ولوحة قبطان للإدارة.

## التشغيل
```bash
npm ci && npm start       # Node 20+ (المكتبة الوحيدة: pg، لـ Postgres)
PORT=8080 node server.js  # منفذ مخصص
```
في أول تشغيل يُنشأ `data/state.json` ويُكتب `data/SECRETS.txt` (صلاحية 600) وفيه كلمة مرور المدير ورموز اللاعبين وأكواد الانضمام للطواقم.
متغيرات البيئة: `PORT`، `DATA_DIR`، `SECRETS_FILE`.

## الاختبارات
```bash
npm test                                                               # اختبارات الخادم (ملفات)
TEST_PG_ADMIN_URL=postgres://postgres@127.0.0.1:5432/postgres npm test  # نفس الاختبارات على Postgres
NODE_PATH=/path/to/node_modules node tests/e2e.js                      # Playwright: جوال 390×844 ولابتوب 1440×900
```

## البنية
- `server.js`: خادم HTTP مع جلسات بكوكيز HttpOnly، وتشفير الرموز بـ scrypt، وحد لمحاولات الدخول، وحماية CSRF، وتحديثات فورية عبر SSE
- `shared/game.js`: قواعد اللعبة والأرقام والخريطة، مشترك بين الخادم والمتصفح
- `public/`: الواجهة (index.html و styles.css و app.js و admin.js) والصور (webp) والخطوط (woff2)
- `data/`: الحالة والأسرار والأعلام المرفوعة، **لا تشاركه**

## التخزين
- بدون `DATABASE_URL`: ملف `data/state.json` والأعلام في `data/uploads/`
- مع `DATABASE_URL`: Postgres. الحالة كلها صف jsonb واحد في جدول `app_state`، والأعلام bytea في `app_files`. الجداول تنشأ تلقائياً، والبيانات التجريبية تنزرع إذا القاعدة فاضية.

## متغيرات البيئة
| المتغير | الوصف |
|---|---|
| `PORT` | منفذ السيرفر (Render يحدده تلقائياً) |
| `DATABASE_URL` | رابط Postgres (اختياري، وبدونه يستخدم الملفات) |
| `ADMIN_PASSWORD` | كلمة مرور حساب `admin`. إذا ما انحطت تتولد عشوائياً وتنكتب في `data/SECRETS.txt` وما تطلع في السجل. وإذا انحطت هي المعتمدة دائماً |
| `PGSSL` | `require` أو `disable` (اختياري، يتحدد تلقائياً) |
| `DATA_DIR`، `SECRETS_FILE` | مسارات اختيارية |

## النشر على Render
1. ارفع المستودع على GitHub.
2. في Render: New ← Blueprint ← اختر المستودع. `render.yaml` ينشئ خدمة ويب مجانية وقاعدة Postgres مجانية `archipelago-db`، ويربط `DATABASE_URL` تلقائياً، ويولّد `ADMIN_PASSWORD` (تلقاه في Environment).
3. ادخل بالاسم `admin` وكلمة المرور، وأنشئ الطواقم من لوحة القبطان أو عدّل الطواقم التجريبية.

قيود الخطة المجانية:
- خدمة الويب تنام بعد ١٥ دقيقة بدون زوار، وأول فتح بعدها ياخذ تقريباً دقيقة
- قاعدة Postgres المجانية تنتهي بعد ٣٠ يوم. للموسم رقّها لخطة مدفوعة صغيرة

الكوكي تصير Secure تلقائياً خلف HTTPS، لأن السيرفر يقرأ `x-forwarded-proto`. ومسار الفحص: `/healthz`.
